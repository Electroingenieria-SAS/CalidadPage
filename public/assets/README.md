# Assets del portal

Los recursos se agrupan por función para que un cambio visual no implique buscar archivos por todo el repositorio.

- `backgrounds/`: fondos de experiencia pública.
- `brand/`: logos y marca.
- `icons/`: favicon e iconos de aplicación.
- `intro/`: video y audio de introducción.
- `modules/`: visuales de Apps, Auditorías, Documentos, Noticias y Publicaciones.
- `notifications/`: GIF/audio de estados y notificaciones.
- `placeholders/`: recursos seguros cuando aún no existe un asset administrado.
- `utility/`: estados, decoración y audios heredados catalogados.

No guardar assets nuevos en la raíz de `public/` salvo archivos web de primer nivel como `og.png`.
